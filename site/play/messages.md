# Messages: tap to finish, Auto, Skip

| Mode | What it does |
|---|---|
| **Normal** | A tap (or OK) shows the rest of the message at once, pauses in the text included. Another tap goes to the next one |
| **Auto** | Each message turns by itself after a moment; longer messages stay longer. Pick **Slow**, **Normal** or **Fast** with ⚙ → **Auto speed** |
| **Skip** | Goes through messages and scrolling text as fast as the game allows |

Change the mode with ⚙ → **Messages** (each tap picks the next one). On a PC, hold <kbd>Ctrl</kbd> to skip only while held.

Auto and Skip never answer for you: Skip stops by itself at a choice, a number to enter or an item to pick, and Auto waits there until you choose. Auto and the Auto speed are remembered in this browser; Skip starts off each time.

Ctrl does nothing when one of the game's plugins already uses it. Some sites have message modes turned off by the person who set up the game or by the game's creator.
